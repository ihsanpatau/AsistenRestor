❓ Pertanyaan Umum (FAQ)

Bagaimana cara mengatur menu restoran?

Buka menu Produk di dashboard, lalu tambahkan kategori dan item menu beserta harga dan fotonya. Perubahan akan langsung tampil di halaman menu pelanggan.

Bagaimana cara menghubungkan rekening bank / pembayaran?

Masuk ke Pengaturan → Rekening, lalu lengkapi data rekening bank kamu untuk menerima pembayaran dari pelanggan.

Aplikasi tidak bisa dibuka atau error, harus bagaimana?

Coba tutup dan buka ulang aplikasi, pastikan koneksi internet stabil. Jika masalah masih terjadi, hubungi tim support melalui WhatsApp di atas.

Bagaimana cara install aplikasi RestoranKu di HP?

Buka halaman Download dari menu pengaturan untuk panduan instalasi lengkap di Android maupun iOS.

Berapa lama waktu respon tim support?

Tim kami biasanya merespon dalam 1-3 jam pada jam operasional. Untuk kendala mendesak, silakan hubungi via WhatsApp untuk respon lebih cepat.
